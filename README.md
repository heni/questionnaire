# Генератор Excel-анкет из YAML

## Запуск

```bash
python questionnaire_to_excel.py questionnaire.yaml output.xlsx
```

Требуются Python 3, `PyYAML` и `artifact_tool`.

## Структура YAML

```yaml
title: "Название анкеты"
students: 40
student_label: "Ученик {n}"
statistics: true

student_fields:
  - ФИО
  - Класс
  - Возраст
  - Код учащегося

sections:
  - name: "Часть А"
    questions:
      - id: 1
        text: "Текст вопроса"
        options:
          - code: а
            text: "Первый вариант"
          - code: б
            text: "Второй вариант, даже если внутри есть запятые"
```

`options` можно записывать и короче:

```yaml
options:
  - "Первый вариант"
  - "Второй вариант, с запятой"
  - "Третий вариант"
```

Тогда коды (`а`, `б`, `в`, ...) назначаются автоматически.

## Что генерируется

Для каждого элемента `sections` создаётся лист ответов:

- `A` — номер вопроса;
- `B` — текст вопроса;
- начиная с `C` — по одной колонке на ученика;
- над колонками учеников размещаются строки `student_fields`;
- каждая ячейка ответа имеет выпадающий список с полным текстом вариантов;
- варианты для Data Validation хранятся в служебных колонках справа на **том же листе**, поэтому запятые в тексте ответов не разбивают пункты списка;
- объединённые ячейки не используются.

Если `statistics: true`, для каждого раздела создаётся лист `Статистика <раздел>`, где для каждого вопроса и каждого варианта формулой `COUNTIF` считается число выбравших его учеников.

## Настройка числа учеников

Достаточно изменить:

```yaml
students: 25
```

Количество колонок ответов, диапазоны статистики и положение служебных данных пересчитываются автоматически.

## Настройка полей ученика

Например:

```yaml
student_fields:
  - ФИО
  - Группа
  - Дата рождения
  - Код
  - Комментарий
```

Число строк верхней формы рассчитывается автоматически.
